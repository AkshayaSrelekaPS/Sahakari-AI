# 🌸 Sahakari AI — Interactive Web Dashboard

This directory contains the full interactive web application for **Sahakari AI**, built with Streamlit, OpenCV, and Web Speech synthesis.

## 🚀 How to Run

From this directory:
```bash
streamlit run app.py
```

Or from the project root:
```bash
streamlit run dashboard/app.py
```

## 📁 Essential Files in this Folder

* **`app.py`**: The core production dashboard application featuring:
  * Multilingual Gateway Login (English, Tamil, Kannada, Hindi)
  * Dual-Role Architecture: SHG Cluster Leader Command Desk & Artisan Member View
  * Morning Roll-Call & Machine Calibration Studio
  * 7-Phase Agentic Rebalancing Simulator (Day 4 emergency handling with member consent)
  * Itemized Unit Economics BOM (Anti-underpricing testing against 3 financial baselines)
  * Assistive Computer Vision Quality Pre-Screening (OpenCV Laplacian blur & Hough placket linearity)
  * Democratic Micro-Payroll Quorum & Immutable Ledger
  * Vernacular Web Speech Audio Passbook for low-literacy home artisans
* **`.streamlit/config.toml`**: Native Streamlit dark theme configuration with obsidian background (`#0b0f19`) and electric indigo accents (`#6366f1`).
* **`requirements.txt`**: Minimal production dependencies needed to run the dashboard.
* **`Sample shirt.png`**: Standard garment reference visual.
